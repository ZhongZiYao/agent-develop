## 🎯 每周学习节奏建议

### 时间分配（按学习者每日 2-3h）
| 时段 | 内容 |
|------|------|
| 0:00-0:30 | 看文档/论文 |
| 0:30-2:00 | 写代码 |
| 2:00-2:30 | 跑测试 + 写博客 |

### AI Coding 工作流（vibe coding）
1. **每个 Phase 开始前**：先让 Claude Code 帮你生成骨架
2. **写代码时**：用 Skill（如 `code-review`）辅助
3. **debug 时**：把 trace 喂给 Claude Code 分析
4. **写博客时**：让 Claude Code 帮你梳理代码生成初稿

### 关键 Skill 推荐
| Skill | 用途 |
|-------|------|
| `init` | 初始化 CLAUDE.md |
| `code-review` | 每周代码审查 |
| `verify` | 验证 RAG 端到端跑通 |
| `deep-research` | 调研论文 |
| `frontend-design` | Streamlit 美化 |
