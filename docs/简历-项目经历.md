# 简历项目经历 — FinGuide AI 银行理财 RAG 问答系统

> **岗位**：AI Agent 实习（华为）
> **总字数**：约 200 字（精炼凝练）
> **三段式**：项目背景 / 主要职责 / 项目成果

---

## 项目背景

面向银行理财领域，从零构建 RAG + 多 Agent 智能问答系统，处理 22 家银行 23,229 份真实理财 PDF（产品说明书 / 业绩基准 / 费率公告），替代游戏场景后项目工程深度与合规要求显著提升。

## 主要职责

负责端到端系统设计：① 搭建 RAG 全链路（PyMuPDF 双引擎解析、表格感知切分、Hybrid 召回与 Rerank、LangGraph 多 Agent）；② 设计金融域 ETL 流水线（PDF → chunks → DuckDB 数仓 → Chroma 向量库），含分批、增量、并发 Embedding；③ Prompt 工程化（风险提示硬约束、专有名词原文保留、业绩基准附带生效日期）；④ 前端金融化与 SSE Trace 时间线可视化；⑤ 单测与端到端验证。

## 项目成果

完成从 Naive → Advanced → Modular → Agentic → Multi-Agent → Self-RAG 的渐进式演进。Phase 8 金融域改造中，100 PDF POC 端到端 < 5 分钟跑通（DuckDB 48 docs / 662 chunks / 662 vectors），Embedding 改 16 并发后预计提速 5-10x。Prompt 100% 必带风险提示，PDF 元数据抽取（机构 / 类型 / 生效日期 / 产品编号）覆盖率 ≥ 95%，28 个单测全绿。
