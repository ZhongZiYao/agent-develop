## 1. 为什么改投国内数据源

**问题**：现有 `fandom_spider` 跑的是英文社区 wiki（Fandom 是英文为主），存在 3 个硬伤：

1. **内容偏元数据**：Fandom 是"图鉴式"——角色列表 + 技能数值 + 皮肤图片，**缺少真实中文玩家写的"怎么打"/"配队思路"/"活动流程"**
2. **Cloudflare 拦**：国内直接访问 Fandom 全 403，必须挂代理，对学习场景额外复杂度
3. **国内 RAG 场景不匹配**：面试 demo 问"妖刀姬 S13 怎么连招"，Fandom 答的是英文技能描述，玩家看不懂

**目标**：换成中文一手攻略语料，覆盖阴阳师 / 原神 / 永劫无间 / 第五人格。

## 3. 各数据源技术细节

### 3.1 S1 — B 站专栏（推荐 P0）

**入口**：
- 列表 API：`https://api.bilibili.com/x/article/encyclopedias?cid={category_id}&pn={page}&ps=20`
- 专栏内容 API：`https://api.bilibili.com/x/article/view?id={article_id}`
- 游戏分类（cid）：
  - 原神：cid=145
  - 崩坏：星穹铁道：cid=171
  - 明日方舟：cid=149
  - 阴阳师：cid=181

**正文格式**：JSON 返回，HTML 片段 `content.body` 字段

**反爬**：
- 必须带 `Cookie: SESSDATA=xxx`（随便一个有效 SESSDATA 即可看公开内容）
- UA：`Mozilla/5.0 ... Chrome/124.0.0.0`
- `Referer: https://www.bilibili.com/read/cv{article_id}`

**风险**：SESSDATA 失效需要重新获取；反爬升级要 fallback 到 Playwright

---

### 3.2 S2 — 米游社 BBS（P1）

**入口**：
- 帖子列表：`https://bbs.mihoyo.com/$_proxy/forum.php?mod=guide&view={fid}`
- 帖子详情：`https://bbs.mihoyo.com/$_proxy/article/{id}`
- 游戏 fid：
  - 原神：fid=43
  - 崩坏：星穹铁道：fid=49
  - 崩坏 3：fid=44
  - 绝区零：fid=58

**正文格式**：HTML，需 BeautifulSoup 解析 `.bbs-content` 或 `#ContentCn`

**反爬**：
- `$_proxy` URL 前缀（CDN 防爬）
- `Cookie: _ga=xxx; _gid=xxx` + `MihoyoBBS_JSESSIONID=xxx`（首次访问 Set-Cookie）
- 频率限制：单 IP 每分钟 < 30 次

**风险**：CDN IP 列表可能更新；cookie 需动态刷新

---

### 3.3 S3 — NGA 精华（P1）

**入口**：
- 版块列表：`https://bbs.nga.cn/thread.php?fid={fid}&order_by=postdatedesc`
- 帖子详情：`https://bbs.nga.cn/read.php?tid={tid}`
- 精华：`https://bbs.nga.cn/thread.php?fid={fid}&order_by=postdatedesc&filter=type&type=4`（type=4 是精华）
- 游戏版块：
  - 阴阳师：fid=601
  - 原神：fid=619
  - 永劫无间：fid=672

**正文格式**：HTML，`.postcontent` / `#postcontent` 容器

**反爬**：
- IP 级频率限制（< 60 req/min）
- 无登录态可读公开帖，但需带 UA

**风险**：IP 被封需换代理

---

### 3.4 S4 — 网易大神（P2，需登录态）

**入口**：
- 游戏专题页：`https://ds.163.com/game/{game_id}/`
- 攻略列表：`https://ds.163.com/api/v1/article/list?gameId={game_id}&page=1`
- 攻略详情：`https://ds.163.com/article/{id}/`
- 游戏 ID：
  - 阴阳师：游戏 ID 自行从页面提取
  - 永劫无间：同上

**正文格式**：HTML，`.article-content` 容器

**反爬**：
- 需登录态（手机号 + 短信验证码 OR 微信扫码）
- 部分接口需 `Authorization: Bearer xxx`
- 反爬升级频繁，建议走 Playwright

**风险**：登录态维护成本高；接口加密参数逆向难度大

**降级方案**：用 cookie 持久化 + Playwright 拿 cookie，再走 API

---

### 3.5 S5 — 旅法师营地（可选 P3）

**入口**：`https://www.iyingdi.com/web/article/list?fid={fid}`

**反爬**：需登录态 + 风控

**风险**：风控严，建议 Phase 8 之后

## 4. 数据落盘规范

### 4.1 统一字段

`src/crawlers/items.py:6` 已定义 `GameDocumentItem`，所有 spider 共用：

```python
doc_id          # 16 字符 URL hash
source          # 'bili' / 'mihoyo' / 'nga' / 'netease_ds' / 'fandom'
game            # 'onmyoji' / 'genshin' / 'yjwj' / 'arknights'
url             # 原始 URL
title           # 标题
author          # 作者
publish_date    # ISO 8601
language        # 'zh' / 'en'
raw_html        # 原始 HTML
clean_text      # Markdown 清洗后正文
word_count      # 字符数
quality_score   # 0-1
crawl_ts        # 爬取时间戳
```

### 4.2 双格式落盘

每条数据同时存：
- `data/raw/jsonl/{source}/{YYYY-MM-DD}.jsonl` — 完整元数据，便于 ETL 流式处理
- `data/raw/md/{source}/{title_slug}.md` — 单文件 Markdown，便于人读 + RAG 切片

详见 Commit 3 的 `src/etl/to_markdown.py`。

## 6. 风险与回退

| 风险 | 影响 | 回退 |
|---|---|---|
| 登录态失效 | S2/S3/S4 全停 | 走 Playwright 重新拿 cookie，30 分钟恢复 |
| CDN IP 变更 | S2 米游社全停 | 切换 Playwright（参照 Phase 7.3 Fandom 经验） |
| 接口加密 | S4 网易大神 P0 拦死 | 降级到只爬游戏专题页（HTML 静态） |
| 反爬升级 | 任意源 | 自动 fallback 到 Playwright DownloadHandler |

## 7. 合规声明

本项目**仅用于学习/面试 demo**，所有爬取内容：
- 不做商用分发
- 标注来源（每条数据带 `source` / `url` 字段）
- 尊重 robots.txt（已对生产 spider 设置 `ROBOTSTXT_OBEY=True`，POC 调试阶段 False）
- 不爬取用户隐私数据
